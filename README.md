# Fuente de Alimentación Regulable

 Esta Fuente de Alimentación hecha de manera casera integra de manera embebida un modulo **LM2596** y un **puente rectificador de diodos** haciendo posible la conversión de AC a DC, todo en una misma placa **doble faz** aplicando conocimientos de Electronica tanto de **Corriente Alterna** como **Corriente Continua** 

 ## Caracteristicas

- Integra un modulo lm2596 **Embebido**

- Un puente rectificador de diodos

- Placa de doble cara o **doble faz**

- La tensión que regula es de **1,25V** hasta **20V** DC

- Corriente maxima de salida de **2 A**

- Protección contra inversión de polaridad
